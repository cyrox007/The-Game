# The-Game

Учебный браузерный проект 2022 года на чистом JavaScript и Canvas.

Сейчас репозиторий оформлен как небольшой архив из двух самостоятельных экспериментов:

- **Dino** — runner с прыжком, препятствиями, счётом и лучшим результатом;
- **Breakout** — ранняя Canvas-аркада с платформой, мячом, кирпичами и жизнями.

Проект сохранён публичным как часть истории обучения и не позиционируется как production-игра или пример текущей архитектуры. Рабочая версия запускается напрямую через GitHub Pages:

https://cyrox007.github.io/The-Game/

## Что здесь отрабатывалось

- работа с Canvas API;
- игровой цикл на `requestAnimationFrame`;
- простые игровые сущности и столкновения;
- управление состоянием сессии через `sessionStorage`;
- работа со звуком и браузерными событиями;
- управление с клавиатуры, мыши и pointer events.

## Технический cleanup

В 2026 году live-demo получил небольшой технический проход без переписывания проекта с нуля:

- обе игры разведены по отдельным страницам и объединены общим стартовым экраном;
- Dino: счёт отвязан от FPS;
- Dino: генерация препятствий запускается только после старта игры и останавливается при завершении;
- Dino: звуки переиспользуются вместо создания новых `<audio>` на каждое нажатие;
- Dino: удаление объектов за пределами поля больше не использует отложенные `splice` внутри `forEach`;
- Breakout: восстановлен как доступная вторая игра;
- Breakout: игровой цикл теперь запускается явно и корректно завершается;
- Breakout: старые `keyCode` заменены на современные `event.key`;
- размеры Canvas и интерфейс аккуратнее ведут себя на небольших экранах;
- обе игры приведены к общей визуальной оболочке.

Цель изменений — оставить старые учебные проекты узнаваемыми, но сделать публичное демо аккуратнее, стабильнее и честнее по отношению к их возрасту и назначению.
