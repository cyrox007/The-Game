# The-Game

Небольшой учебный браузерный проект 2022 года на чистом JavaScript и Canvas.

Проект сохранён публичным как часть истории обучения и не позиционируется как production-игра или пример текущей архитектуры. Рабочая версия запускается напрямую через GitHub Pages:

https://cyrox007.github.io/The-Game/

## Что здесь отрабатывалось

- работа с Canvas API;
- игровой цикл на `requestAnimationFrame`;
- простые игровые сущности и столкновения;
- управление состоянием сессии через `sessionStorage`;
- работа со звуком и браузерными событиями.

## Технический cleanup

В 2026 году live-demo получил небольшой технический проход без переписывания проекта с нуля:

- счёт отвязан от FPS;
- генерация препятствий запускается только после старта игры и останавливается при завершении;
- звуки переиспользуются вместо создания новых `<audio>` на каждое нажатие;
- удаление объектов за пределами поля больше не использует отложенные `splice` внутри `forEach`;
- размеры Canvas рассчитываются по viewport;
- обработчик клавиатуры перехватывает только нужную клавишу.

Цель изменений — оставить старый учебный проект узнаваемым, но сделать публичное демо аккуратнее и стабильнее.
